# AI Forensic Readiness v0.2 — Discussion Draft

This release completes the ten synthetic reference investigations and supplies a
testable evidence profile for consequential AI actions.

- Ten investigation bundles and twenty deterministic failure/control conditions.
- 158 normalized events and 120 manifested artifacts.
- Evidence references, content-chunk identity, memory lineage, delegated authority,
  approval presentation, scoped validation and explicit evidence gaps.
- OCSF 1.6.0 and OpenTelemetry logical-model projections with source preservation.
- Schema conformance checks, integrity checks and 47 research regression tests.
- A specification, practitioner briefing, cross-case findings and technical review kit.

**Archive DOI:** [10.5281/zenodo.22677119](https://doi.org/10.5281/zenodo.22677119).
The PDFs and source ZIP match the existing Zenodo deposit. The source commit is
`2db88053c8579e4db7aa6a5a45ea4c325a787ec9`. `SHA256SUMS.txt` records the attached
archive files' hashes. This GitHub release links the existing archive; it does not
require a second Zenodo version.

All cases are synthetic. The experiments do not establish production control
effectiveness, independent reviewer performance, real-model behavior or live
collector interoperability. OpenTelemetry output is logical-model JSON, not OTLP
wire JSON. Hash manifests establish consistency against a trusted reference, not
signer authentication. Archived files retain their original pre-publication wording;
use the DOI above for citation.
